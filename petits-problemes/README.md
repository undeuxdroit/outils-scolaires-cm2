# Les petits problèmes

Application de mathématiques destinée à travailler la compréhension des problèmes au niveau CM2.

## Fonctionnement

- neuf problèmes présentés un par un ;
- choix de l’opération avant le calcul ;
- saisie de la réponse avec un nombre entier ou décimal ;
- seconde page présentant, pour chaque problème, le calcul correct et une explication pédagogique ;
- lecture orale de l’énoncé lorsque le navigateur le permet.

L’application fonctionne entièrement dans le navigateur et ne collecte aucune donnée.

Pour l’utiliser localement, ouvrir `index.html` dans un navigateur.
