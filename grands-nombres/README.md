# Atelier des grands nombres

Application pédagogique de CM2 pour s’entraîner à :

- reconnaître la valeur des chiffres dans un grand nombre ;
- compléter un tableau de numération ;
- décomposer un nombre ;
- écrire un nombre en lettres.

## Utilisation

Ouvrez le fichier index.html dans un navigateur. L’application fonctionne sans compte, sans collecte de données et sans installation de dépendances.

Une version en ligne est également disponible : [ouvrir l’atelier](https://atelier-grands-nombres.undeuxdroit.chatgpt.site).

## Accessibilité

L’interface propose de grands boutons, un pavé numérique à l’écran, des consignes courtes, une lecture audio selon le navigateur, des indices et des essais illimités. Aucun chronomètre ni glisser-déposer n’est imposé.
